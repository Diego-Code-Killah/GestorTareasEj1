# GestorTareas 2027
Proyecto de introducción al curso 2027
## Todo-List v0.1

Pequeña aplicacion para gestion de lista de tareas desde la consola

## Funcionalidad
1. Añadir una nueva tarea
2. Borrar una tarea
3. Listar tareas pendientes
4. Marcar una tarea como completada

## Implementacion
- Se usa la **version de java** JDK27
- Almacenamiento de tareas en memoria usando ``Arraylist``
- Gestión del UI con ``println`` y ``Scanner``.
